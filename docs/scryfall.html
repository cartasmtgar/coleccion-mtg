Iconos de maná y habilidades — GET /symbology

Cada símbolo trae svg_uri (ej https://svgs.scryfall.io/card-symbols/W.svg). Abajo ves ambas formas para que elijas.

  

    
Opción A — <img src="https://svgs.scryfall.io/card-symbols/W.svg"> (dependiente de Scryfall, cache CDN)

    

  

  

    
Opción B — SVG inline (fetch y pegar <svg> en el HTML, sin dependencia externa, puedes recolorear con CSS)

    

  

  
Tip: para recolorear inline usa svg [fill] { fill: currentColor } y cambia class="text-amber-400" en el contenedor.
